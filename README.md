# نقوصات ومشتريات مقهى منخل

برنامج عربي بسيط لتنظيم المواد الناقصة في المقهى، ومتابعة شرائها واستلامها، ومعرفة المبالغ المدفوعة والديون المتبقية.

**[افتح الموقع](https://munkhuliq.github.io/mankhul-shortages/)** ثم سجّل الدخول بحسابك الحالي. الواجهة منشورة على GitHub Pages، وتسجيل الدخول والبيانات محفوظة في خادم Cloudflare وقاعدة D1.

## كيف يعمل؟

1. **المخزن:** يسجل المادة الناقصة والكمية المطلوبة.
2. **المشتريات:** تسجل ما تم شراؤه والسعر والمورد، وتحدد الدفع نقدًا أو دينًا.
3. **المخزن:** يؤكد الكمية المستلمة ويسجل أي نقص.

إذا بقيت كمية ناقصة، يمكن طلبها مرة أخرى دون مسح الشراء السابق. ويظل الدين محفوظًا حتى تسديده.

## الأقسام الموجودة

| القسم | وظيفته |
|---|---|
| المخزن | تسجيل النواقص ومطابقة الاستلام |
| المشتريات | تسجيل الشراء الكامل أو الجزئي والشراء المباشر |
| السجل | البحث والتصفية ومراجعة المصروفات والديون |
| الموظفون | إنشاء الحسابات وتحديد الصلاحيات، للمدير فقط |

يدعم البرنامج الأولويات، وكشف ديون حسب المورد، وسجل العمليات، والطباعة، وتصدير CSV الذي يفتح في Excel. الواجهة مناسبة للهاتف ويمكن تثبيتها للوصول السريع.

## التشغيل على الكمبيوتر

ثبّت **Node.js 22 أو أحدث**، ثم افتح PowerShell داخل مجلد المشروع ونفّذ:

```powershell
npm ci
```

في أول تشغيل لنسخة جديدة، اختر كلمة مرور مدير قوية من 8 أحرف على الأقل:

```powershell
$env:INITIAL_ADMIN_PASSWORD = 'اكتب هنا كلمة مرور قوية تختارها'
npm start
```

افتح [البرنامج محليًا](http://localhost:3000). اسم دخول المدير الأول هو **admin**. أنشئ حسابات المخزن والمشتريات من تبويب الموظفين.

بعد إعداد الحسابات، يكفي تشغيل `npm start` أو ملف `start-app.bat`. للفتح من هاتف على نفس الشبكة، استخدم عنوان IPv4 للكمبيوتر مع المنفذ `3000`.

## أين تحفظ البيانات؟

- التشغيل المحلي: في ملف `data/store.json`، ويُنشأ عند الإعداد الأول.
- يمكن تشغيل نسخة Node مع PostgreSQL، أو نشر نسخة Cloudflare مع D1.
- هذه مصادر بيانات مستقلة؛ لا تتزامن تلقائيًا مع بعضها.

هذا المستودع يحتوي **كود البرنامج فقط**. بيانات المقهى وكلمات المرور والأسرار وملفات التشغيل المؤقتة لا تُرفع إليه. احفظ نسخًا احتياطية من قاعدة البيانات.

الإضافة والتعديل تحتاجان اتصالًا بالخادم؛ التثبيت على الهاتف لا يوفر عملًا كاملًا دون إنترنت. إعداد الربط موجود في `public/config.js`، والخادم يسمح بطلبات موقع GitHub المحدد في `wrangler.jsonc`.

## فحص البرنامج

```powershell
npm run check
npm test
```

الاختبارات تستخدم بيانات مؤقتة، ولا تغيّر بيانات المقهى.
