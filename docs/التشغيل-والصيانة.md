# نقوصات ومشتريات مقهى منخل

برنامج بسيط للمخزن والمشتريات والمدير: طلب نقص ← شراء ← استلام، مع حفظ المصروفات والديون في السجل نفسه.

## تشغيل النسخة المحلية

يتطلب Node.js 22 أو أحدث. من مجلد البرنامج:

```powershell
npm ci
npm start
```

افتح `http://localhost:3000`. قاعدة JSON الحالية موجودة في `data/store.json`. عند التشغيل الأول بعد التحديث، تُحوّل كلمات المرور القديمة إلى تجزئات دون تغيير كلمات الموظفين أو المواد، ثم يبدأ الخادم. يحتاج الموظفون إلى تسجيل الدخول مجددًا لأن معرّف الموظف لم يعد جلسة دخول. تُنشأ جلسة سرية مدتها سبعة أيام؛ الخروج وتغيير كلمة المرور وحذف الحساب يبطلون الجلسات المناسبة.

عند إعداد نسخة جديدة لا تحتوي قاعدة بيانات، اضبط كلمة مرور مدير تختارها بنفسك، بطول 8 أحرف على الأقل:

```powershell
$env:INITIAL_ADMIN_PASSWORD = 'ضع هنا كلمة مرور قوية تختارها'
npm start
```

اسم الدخول الأول هو `admin`. أنشئ موظفي المخزن والمشتريات من تبويب الموظفين. لا يعاد إنشاء الموظفين المحذوفين، ولا توجد كلمات مرور ابتدائية ثابتة في المصدر. لا يلزم متغير الإعداد عند وجود حسابات في قاعدة البيانات. غيّر أي كلمات ابتدائية قديمة من حساب المدير.

لتشغيل نسخة اختبار أو قاعدة أخرى، يمكن تحديد `DATA_DIR` و`PORT`. شغّل **عملية Node واحدة** لكل قاعدة JSON؛ الملف المحلي ليس قاعدة مشتركة بين عدة خوادم. ملفا `start-app.bat` و`start-online.bat` يعملان من مجلدهما؛ عنوان الهاتف داخل الشبكة هو عنوان IPv4 الفعلي للكمبيوتر، وليس عنوانًا ثابتًا. رابط tunnel يربط الهواتف بالقاعدة المحلية نفسها ما دام الخادم والنفق يعملان.

## قواعد العمل بعد التصحيح

- المخزن يطلب المواد ويؤكد الاستلام ويعيد طلب الناقص؛ المشتريات تسجل الشراء وتسدد الديون؛ المدير يدير الحسابات ويصحح بيانات الشراء.
- السعر هو **إجمالي شراء المادة** بالدينار العراقي، وليس سعر القطعة.
- الاستلام الناقص لا يلغي فاتورة الشراء أو الدين. حتى لو استلمت كامل الشراء الجزئي، يبقى باقي المطلوب ظاهرًا كنقص.
- «طلب مرة أخرى» ينشئ سجلًا جديدًا. في المادة الناقصة يطلب الكمية المتبقية، وفي المادة المكتملة يطلب الكمية الأصلية من جديد. لا ينشئ طلبًا آخر إذا كان هناك طلب متابعة مفتوح لنفس السجل.
- لا يمكن حذف مادة مشتراة أو عليها دين، ولا تغيير الدفع عبر التعديل العام. استخدم زر التسديد لتسديد الدين الكامل.
- شاشة «المسار» تحفظ اسم منفذ العملية وتاريخها، وتتضمن تعديل البيانات والتسديد. توثيق الأحداث يبدأ بعد التحديث؛ لا يمكن استنتاج الأحداث القديمة المفقودة.
- عند تغيير مادة من جهاز آخر، قد يطلب البرنامج تحديث القائمة بدل الكتابة فوق التغيير.
- التنبيهات محفوظة سبعة أيام، وتعرض الواجهة أحدث 100 تنبيه. ليست خدمة Push تضمن التنبيه عندما يكون التطبيق مغلقًا.
- التصدير CSV قابل للفتح في Excel، مع تواريخ بغداد المطلقة وحماية الخلايا النصية وتجميع الكميات حسب الوحدة.
- التثبيت PWA يوفر فتحًا سريعًا. إضافة المواد وتحديثها تحتاج اتصالًا؛ لا يوجد طابور عمليات دون إنترنت. تظهر حالة الاتصال في الشريط العلوي.

## PostgreSQL وCloudflare

عند ضبط `DATABASE_URL` تستخدم نسخة Node قاعدة PostgreSQL بدل JSON. يبدأ الخادم بعد اكتمال التهيئة، ويستخدم الشكل نفسه لبيانات الواجهة. التحقق من شهادة PostgreSQL مفعّل؛ يمكن توفير شهادة الجهة الموثوقة عبر `PGSSL_CA`. قيمة `PGSSL=disable` مخصصة لاتصال PostgreSQL محلي موثوق لا يستخدم TLS، وليست حلًا لأخطاء شهادة قاعدة بعيدة.

نسخة Cloudflare تستخدم `src/index.js` وقاعدة D1 المحددة في `wrangler.jsonc`. تُضاف أعمدة الحفظ الجديدة تلقائيًا دون مسح السجلات. إذا كانت القاعدة جديدة تمامًا، اضبط `INITIAL_ADMIN_PASSWORD` كسرّ Cloudflare قبل أول تشغيل، من لوحة Cloudflare أو بأمر `wrangler secret put INITIAL_ADMIN_PASSWORD`. هذا غير مطلوب للحسابات الموجودة.

النشر يتم من `deploy-to-cloudflare.bat` أو `wrangler deploy` بعد مراجعة التغييرات. **الإصلاحات المحلية لا تُحدّث الموقع المنشور تلقائيًا.** JSON وPostgreSQL وD1 قواعد مستقلة؛ اختر مصدر البيانات المعتمد ولا تتوقع انتقال البيانات بينها دون ترحيل.

## التحقق

```powershell
npm run check
npm test
npm audit
```

الاختبارات تعمل على JSON مؤقت وD1 محلي عبر workerd/Miniflare، وتبني Worker بوضع `--dry-run` دون نشر. تختبر الدخول والصلاحيات والديون والاستلام وإعادة الطلب وفشل الحفظ والتعديل المتزامن والجلسات وSocket.IO وCSV. لا تحتاج إلى خادم إنتاج على المنفذ 3000، ولا تستخدم بيانات مقهى منخل. `test.js` و`test-auth.js` يشغلان المجموعة الآمنة نفسها.

## النسخ الاحتياطي

احتفظ بنسخ مؤرخة من `data/store.json` خارج مجلد البرنامج، خصوصًا قبل أول تشغيل للتحديث. توجد نسخة `.bak` للكتابة السابقة، لكنها لا تعوّض النسخ الدورية. إذا فسد الملف، يتوقف البرنامج عن الحفظ بدل إنشاء قاعدة فارغة. أوقف الخادم، واحفظ الملف المعطوب جانبًا، ثم استعد نسخة سليمة وأعد التشغيل. عند استخدام PostgreSQL أو D1 اعتمد النسخ والاستعادة الخاصة بتلك القاعدة.

قاعدة البيانات المحلية مستبعدة من Git مع إبقاء ملفها على الجهاز. أي بيانات سبق رفعها إلى تاريخ المستودع لا تختفي بمجرد استبعاد الملف؛ تغيير كلمات الدخول القديمة مطلوب إذا سبق مشاركتها.
